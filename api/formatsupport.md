# FormatSupport

Flags supported by a custom format from [Plugin:newFileFormat()](plugin.md#pluginnewfileformat).

## FormatSupport.RGB

The format supports the [RGB](https://en.wikipedia.org/wiki/RGB_color_model) color mode.

## FormatSupport.RGBA

The format supports the RGBA color mode (RGB with an [Alpha](https://en.wikipedia.org/wiki/Alpha_compositing) (opacity) component).

## FormatSupport.GRAY

The format supports the [grayscale](https://en.wikipedia.org/wiki/Grayscale) color mode.

## FormatSupport.GRAYA

The format supports the grayscale color mode with an Alpha component.

## FormatSupport.INDEXED

The format supports the [Indexed](https://en.wikipedia.org/wiki/Indexed_color) color mode.

## FormatSupport.LAYER

The format supports layers.

## FormatSupport.FRAME

The format supports frames.

## FormatSupport.PALETTE

The format supports palettes.

## FormatSupport.PALETTE_ALPHA

The format supports palettes with an Alpha component.
